# My Universe Darling

Create an ultra-premium romantic interactive website using HTML, CSS, and JavaScript only. The website should feel like a magical love story instead of a normal webpage. It must be fully responsive (mobile + desktop), smooth, elegant, emotional, and cinematic.

Theme:

❤️ "To My Miss Universe" ❤️

Color Palette:

- Dark Purple

- Pink

- Rose Gold

- Soft White

- Gold Glow

Design Style:

- Glassmorphism

- Premium UI

- Floating Hearts

- Twinkling Stars

- Rose Petals

- Smooth Animations

- Soft Shadows

- Elegant Typography

- Beautiful Loading Effects

- Heartbeat Animation

- Confetti

- Cursor leaves tiny hearts

- Romantic Background Music with Mute/Play Button
